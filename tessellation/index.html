Relief is determined by the selected ball end mill. A spherical tip creates a round-bottom groove, with maximum depth equal to its radius. No independent draft or relief controls.

Custom interlocking tile · Escher-style

Start with a square. Sculpt its boundary using Bézier points; matching sides are generated automatically. The tile outline, not a free-floating motif, defines the tessellation.

Sliding: top matches bottom, left matches right. Rotational: one edge is rotated to all four sides.

Click an edge to select it. Double-click an edge to add a point. Endpoints remain fixed to keep tile corners joined.

The 2D construction preview updates while dragging. Use Update Custom Preview to rebuild the machined 2D/3D relief, section and STL geometry.

Inverted geometry may not be directly machinable with the selected ball cutter. The cutter sweep is a spherical-tip geometric envelope, not a collision-checked machining simulation.
